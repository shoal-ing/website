02 · HOW IT WORKS

Seed. Simulate. Score.

Jev decides. An LLM speaks only when an agent posts. Everything runs in one Rust binary.

  1. 01→

    Seed

    Shoal parses your post or README into claims, calls to action and install steps, then sets the venue, the posting time and a calibrated baseline.

    launch.md → 3 claims · 1 install
    venue hn · Tue 08:00 PT
  2. 02→

    Simulate

    Ten thousand agents from 38 developer segments read, vote and reply over 48 simulated hours. Jev, the deterministic engine, decides who acts and when. An LLM writes text only when an agent posts.

    10,000 agents · 2,880 ticks
    88 LLM calls · 4.8s wall
  3. 03✓

    Score

    You get the predicted thread, sentiment over time, install intent by segment, the top trust flags and the edits ranked by how much they change the outcome.

    412 pts · peak #3
    3 trust flags · 2 edits
